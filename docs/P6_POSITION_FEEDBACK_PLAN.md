## 1. 研究判断

P5 的半 Actor 学习率带来了实际收益，但主要剩余问题已经不只是“六条动作还没跑完”。保持现有已执行部分不变、把所有未执行尾段补成理论满分，B 的整体回报也只能到 0.792583，仍低于论文的 0.82。必须改善已执行部分的跟踪质量。

现有执行段损失中，全局根位置是最大的单项；当前 Actor 恰好没有当前根位置误差的直接反馈。因此 P6 只研究一个结构性问题：

> 保留 B-24000 的全部已学状态和半 Actor LR，给 Actor 增加当前参考根部相对机器人根部的 XYZ 误差，能否降低长动作漂移、提高跟踪回报，并保持已学动作？

这是本项目依据代码与数据提出的输入补全实验。**SuperMimic 论文未公开 goal 的完整特征与维数，不能称其为已经还原的作者原版。** 仿真中该位置可获得；将来部署需要对应状态估计，实机不在本轮范围。

## 3. 为什么只补失败不够

当前六项正奖励权重总和为 5，均乘 dt=0.02，两项正则非正，所以每步最高奖励为 0.1。每条动作按完整参考长度归一，再对 40 条等权平均。设平均回报为 R，平均完成比例为 C：

\[
1-\bar R=(1-\bar C)+(\bar C-\bar R).
\]

B24000 的未执行尾部缺口为 0.0371581，已执行段质量损失为 0.2074168。**在现有已执行前缀及其奖励保持不变的条件下**，补齐尾部的最好结果为：

\[
\bar R_{\rm tail-only}\le0.7554250+(1-0.96284185)=0.79258315<0.82.
\]

这不是新策略的能力上限；新策略可以同时改善前缀和尾段。它说明只关注成功数不足以指导下一轮。

| B24000 已执行段损失 | 对完整时长归一化回报的影响 |
|---|---:|
| **全局根位置** | **0.0858004** |
| 身体姿态 | 0.0414917 |
| 身体角速度 | 0.0290997 |
| 身体线速度 | 0.0208262 |

根位置损失占执行段损失的 **41.4%**；若用全部 1−R 缺口为分母，则为 35.1%。根位置实际贡献仅 0.0104838，相当于其已执行时间可得奖励的 10.8883%。相对身体位置项已获得约 94.65% 的可得奖励，反映“相对身体位置跟随较好、全局位置仍漂移”的差别。

B 已完整成功的 fightAndSports1_subject4、dance2_subject5、dance2_subject4，其平均 XY 误差仍为 6.1623、6.0674、4.9677 m。这些不是补尾能够解决的问题。不同策略执行长度不同时，不直接用绝对损失大小判定哪一支精度更差。

作者团队的 BeyondMimic 官方 PolicyCfg 包含 motion_anchor_pos_b；实现为参考anchor到机器人anchor坐标系的3维相对位置，无状态估计版本显式移除此项。它支持位置反馈的合理性，也提示其状态估计前提，**不能证明 SuperMimic 的未知 goal 恰好相同**。

## 6. P6 唯一算法差异

| 项目 | A：no_position_feedback | B：root_position_feedback |
|---|---|---|
| 共同父版本 | P5 B24000 | P5 B24000 |
| Actor LR 系数 | 0.5 | 0.5 |
| 公共 future goal | 原710维 | 原710维 |
| Actor encoder 输入 | 710维 | **713维，追加当前相对位置3维** |
| Critic / WM / 奖励 / 终止 | 原设置 | 原设置 |
| 新增联合更新 | 9000 | 9000 |
| 全局目标终点 | 33000 | 33000 |

新增 Actor 输入：

\[
e_p(t)=R(q_{\mathrm{robot}}(t))^\top
\bigl(p_{\mathrm{ref}}(t)-p_{\mathrm{robot}}(t)\bigr)/0.3.
\]

使用当前帧、完整根四元数、机器人自身坐标系，固定0.3 m缩放；不改成世界绝对XYZ、仅yaw坐标、下一帧误差或十帧各加XYZ。不新增clip、噪声或可学习归一化。完整根旋转适合既有robot_root语义，避免为了本轮新增yaw投影。

保留930维历史、32维tanh latent、所有隐藏层与decoder。公共 MotionLibrary.goal 保持710维；仅Actor内部拼接，Critic仍接原710维和已有privileged相对位姿，WM、state/replay表示均保持。

三条正常路径必须使用同一误差函数：

1. 真实collection：当前clip/frame和sim.qpos。
2. H32 imagined rollout：每步的预测state和对应当前参考帧，保留位置与四元数对Actor的梯度；不能detach或固定使用rollout起点误差。
3. 正式evaluate：当前物理状态与参考帧，按checkpoint config构造710/713 Actor。

建议最小接口为 Actor(root_position_feedback=False) 和 actor(history, goal710, root_position_error=None)。反馈组正常调用显式提供误差，不悄悄补零；对照组保留原行为。实际配置记录 actor_root_position_feedback=false/true，actor_root_position_scale_m=0.3。全局每轮 set_schedule 保持两支 Actor scale=0.5；WM/Critic维持原基础LR和余弦进度。

## 9. 预先确定的判断方法

两支每1000新增轮进行同一checkpoint完整40动作评估，保留25000、26000、27000、28000、29000、30000、31000、32000、33000全部节点。固定终点33000；末三节点31000/32000/33000。时间先到则记录并发布真实非整千终点，比较共同完成的迭代，不能将不同更新量包装成等预算结果。

原摩擦、完整参考、无观察噪声/无domain randomization的正式评估口径，原高度/倾斜终止与reward保持。失败尾部计0，40动作等权；不拼接逐动作最好checkpoint、不删难动作。

报告四组相互关联的结果：

1. **总效果**：全40回报、完整数、完成比例、六起身/四跑步身份与各自质量、全节点曲线、固定终点和末三均值/范围。
2. **主要假设**：六正项/两罚项实得贡献、执行段可得上限与缺口，尤其root_position；整体分解1−R=(1−C)+(C−R)。
3. **公平位置比较**：父B24000、A最终、B最终都完整成功的同一动作集合，列名字/数量、逐动作XY均值与集合均值；同时保留全40指标及每条失败，不能靠改变集合隐藏退化。
4. **保持性**：父34成功动作保留/退化/新增，末三成功交集和稳定起身身份。末三checkpoint并非独立seed，不作多seed显著性声称。
