# P8 深读复核：当前复现程度与下一阶段依据

日期：2026-11-07（北京时间）。固定审查提交：`ec870270f56cac91c7bf50b86ced0a8b17cc01ec`。本报告只读分析已发布代码、论文、正式评估及小型训练/物理证据，没有启动新训练、仿真、测试或归档。

## 1. 当前结论

LAFAN1主要回报指标已达到作者参照，这一历史验收保留。P8 H32进一步达到0.86980516、37/40，39/40动作回报高于直接父C42000；仍存在已学技能反复丢失。H16在9个共同节点全部输给H32，不继续缩H。BONES40已经真正完成训练和全子集评估，但姿态质量下降、LAFAN遗忘和高动态技能失败表明大规模控制能力尚未达到论文水平。

本轮新增的明确机制证据是：累计存活已为零的想象后缀仍无权重地训练Critic，造成两次巨额损失。另发现BONES筛选使用了与论文不同的高度定义，且漏掉若干明确名称条件。下一阶段针对这些问题，在稳定性研究与修正后的完整库训练之间并行推进。

### 2.1 H32大多数动作质量提高，一个起身严重回撤

相对C42，H32有39/40条R提高，父36条成功全部保留，新完成jumps1_subject2。唯一R下降的fallAndGetUp1_subject1由129.62s退到9.34s，R .55837551→.03789189，单条拖低全40均值.01301209。fallAndGetUp2_subject3反而由32.28s提高至97.58s。完整数增加但平均完成比例略降，正是不同长动作执行位置变化的结果。

### 2.2 H16退化具有广泛性

H16相对H32的40条R全部更低，相对C42有39条更低。父/H32/H16共同完整30条的R为.90200765/.91613862/.85706465，XY为.06760166/.04556566/.07395645m，SO3为.06329726/.05917286/.09022279rad。H16既更容易失去完整执行，也降低了仍成功动作的跟踪质量。

H16终点丢失的父成功为dance2_subject5、getup1_subject4、getup1_subject5、fight1_subject5、fightAndSports1_subject1、run1_subject2。两路配置和实际代码的H循环、gamma^H、末端V、λ递推均按cfg执行，没有固定32造成的错误证据。

### 2.3 全40都曾完成，但不在同一个策略里

H32九节点成功并集39，唯一未完成dance1_subject1；H16并集39，唯一未完成fallAndGetUp2_subject3。合并18节点覆盖全部40条，不能拼接成单策略40/40。

节点次数不是独立seed成功概率。H32终点保留父36，不等于全程都保留；九个节点仍没有一条起身始终完整。

## 3. 根本机制：终止后想象后缀污染Critic

当前Actor按累计存活S_t加权，但Critic对H×batch全部状态作无权重MSE。WM继续展开已经终止的状态，Actor在这些状态上继续产生动作，动作/状态外推发散，惩罚产生巨大负reward/λtarget，再被共享Critic拟合。

已存4条样本以旧V计算、除以完整32×4096 batch的原始MSE贡献为2,872,000.627和16,122,271,472.708，其中精确零存活后缀贡献2,872,000.626和16,122,271,472.706，几乎全部。用已有S_t加权后，这4条的算术贡献仅.001277/.001875。这只是损失来源分析，不是修正后的训练成绩。

论文Eq.(3)本身写无累计存活权重的MSE，当前代码没有在此抄错。论文同时称其WM可长期稳定展开；当前独立模型的上述外推不具备该前提。P9的存活加权是明确的方法修正，不能伪称作者已公开的默认式，也不能将损失下降本身当控制进步。

H32-49000仍有.87236567/37成功，说明巨额MSE不是整批活跃value普遍爆炸的证据，也不能单独量化这些异常造成多少失败。需要正式续训对照决定实际收益。

### 3.1 上一轮后半段异常并非全是模型假摔

旧38089/41379共8条同动作物理展开中，5条于第23–31步真实终止，8条全部活过16步；另3条在32步仍活着，但预测—物理SO3误差约1.799–2.423rad。因此后半段同时存在真实危险与模型误差。缩到H16可能隐藏真实未来后果，不能把更短目标较高当作优势。

C42000覆盖真实失败的4个WM窗，dance预测death=1；两条getup与jump约.000204/0/.000487，实际均终止。失效边界预测失配成立，但这些是C42000父WM，不是当前H32-51000。

### 4.1 短clip暴露了终点价值与采样的差异

40h/17301平均约8.32s，远短于LAFAN长动作。BONES首次Actor更新iteration6的top4残差中3条自然结束；一条在第8步结束后仍有24个零存活虚拟transition进入Critic拟合。真实collector、Actor回报和λ递推的自然终点mask一致，没有发现Actor越界累计末帧奖励。

ReturnSampler记录有限episode的discounted return，却统一除Gmax=10。即使满奖励，剩1/50/416步的回报也仅.1/3.9499/约9.847，低剩余时长会影响“困难度”。50% uniform仍在，不能说采样全部被尾段占据；目前缺少按剩余时长的实际采样份额。P9先保留单变量Critic对照，新增正常采样中的小型分组统计，不同时修改Gmax、timeout与采样器算法。

## 5. BONES筛选与论文存在确定偏离

原始142220条相同，当前保留133661条、273.21598h；作者为129514条、264.56h。当前名称只排264条，物理再排8295条；作者名称排12553、物理再排153。数量偏差部分抵消，当前集合不是作者集合简单加4147条。

明确问题：
1. 当前prepare_bones_p8.py将最低collision sphere/capsule表面z用于elevated/penetration；论文Appendix E的z_min=min_b z_b是最低body-link高度。仅floating feet应使用foot geom-to-plane距离。
2. 当前名称清单漏掉论文明示的box/chair/sit/climb/jump_off_50cm/look_over_fence等支持物或地形条件。完整作者清单未公开，不意味着已公开项可以省略。

格式部分未发现确定错误：官方文档支持120Hz、cm→m、deg→rad、xyz extrinsic根旋转、按joint_name_dof映射，当前SLERP/根局部角速度/link-origin FK速度语义相符。修正筛选应复用已有CSV和有效NPZ，不重新下载或重转所有正确参考数组。

论文未列筛选body的具体清单；P9使用现有G1全部非world body origins并记录名称，作为文字定义的明确实现选择，不以14个奖励追踪body冒充作者完整集合。

名称借用论文指向的SONIC官方支持物/地形词汇，但不复制其对acrobatics、cartwheel、handstand和roll的排除。避免裸box误杀boxing、裸climb误杀mountain_climber，用明确词边界/动作短语；不靠调词凑作者数量，不按训练失败删动作。
