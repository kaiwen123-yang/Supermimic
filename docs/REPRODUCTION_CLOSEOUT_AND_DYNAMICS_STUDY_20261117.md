### 第一讲建议：一个训练循环中的三件事

1. 用普通物理仿真器收集状态—动作—下一状态数据。
2. 用监督学习拟合可微的动力学模型。
3. 在该模型中展开短时想象轨迹，将回报的梯度用于更新策略。

SuperMimic官方说明：梯度不穿过MuJoCo物理仿真；世界模型与策略在同一循环中持续训练，只在一次策略更新内部固定模型参数。因此，“固定模型参数”不等于把模型forward放进no_grad；输入到输出的梯度路径仍须保留。

来源：[官方方法说明](https://supermimic.github.io/)、[论文v2](https://arxiv.org/abs/2610.28480v2)、[官方policy learner](https://github.com/HybridRobotics/supermimic/blob/7e94b073940b7a19b9a82ff01e191cfb35c4ba91/src/supermimic/learners/policy_learner.py)。

用于学习的抽象表达为：

```text
真实数据：      (x_t, u_t, x_{t+1}) 来自仿真器或以后另行采集的真实系统
模型拟合：      x_hat_{t+1} = f_theta(x_t, u_t, context/history)
策略想象：      u_t = pi_phi(observation/history, goal)
策略梯度路径：  回报 → 预测状态序列 → 动作序列 → 策略参数phi
```

这是概念图，不替代官方代码实际的状态表示、历史长度、奖励/存活权重与Critic公式；逐项定义将在学习时展开。

### 必须分清的四个概念

- **可微学习动力学模型**：数据拟合的函数，对状态/动作输入可求导。其导数是学习模型的导数，不能自动等同真实系统导数。
- **可微物理仿真**：对物理仿真计算过程求导；SuperMimic核心策略训练不要求这一能力。
- **用可微模型做控制优化**：例如MPC/iLQG使用模型及状态/动作局部导数优化控制序列。它不必同时对优化器本身反向传播。
- **可微MPC或可微优化层**：进一步对优化问题的解映射求导；这又是另一层方法，不与“模型可微”混为一谈。

补充阅读：[作者的mpc.pytorch说明](https://locuslab.github.io/mpc.pytorch/)区分动力学Jacobian和对控制器求导；[《Differentiable MPC for End-to-end Planning and Control》](https://proceedings.neurips.cc/paper/2018/hash/ba6d843eb4251a4526ce65d1807a9309-Abstract.html)给出一类固定点处的求导方法。这些作为概念对照，不要求安装该库或重做其示例。

同理，训练模型参数theta与沿模型优化策略参数phi是两个目标；动作历史不自动证明系统满足某个固定Markov假设；模型预测误差低不自动证明梯度有用、接触切换可靠或闭环稳定。

对于MPC的概念示例，可以讨论：

```text
f_hat(x,u) = f_nominal(x,u) + g_theta(x,u,context)
A_t = partial f_hat / partial x
B_t = partial f_hat / partial u
```

这里的加法只在选定一致的坐标/增量表示下成立；姿态等流形量应使用相应的组合/积分，不能直接相加。它只是可研究的残差模型形式，并非SuperMimic源码已实现了用户项目所需的残差MPC，也不保证能修复现有稳定性问题。

可迁移的首先是建模方法、数据闭环、梯度路径和评测思路。G1的模型权重、状态维度、动作缩放、接触分布和执行器接口不能直接搬到Go2、Piper或Revo3。跨机器人通常需要重新定义模型并训练；本次不授权该训练。

学习顺序建议先把模型与梯度原理讲清，再优先梳理MPC＋RL的对应关系，随后讨论臂手接触操作。π系列、导航等方向如以后提出具体问题，再单独判断接口与收益，不把一个世界模型概念强行套入所有项目。
